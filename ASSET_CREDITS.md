# Asset Credits

## Shipped runtime assets

- Bedroom environment and aligned anomaly renders: project-prepared Blender renders based on the **Haunted Interiors Free Bedroom Sampler** by DaddyDarko. Game/media use and modification are permitted; standalone redistribution of the source pack is not. Credit is appreciated by the creator.
- UI primitives, room effects, and game-specific composition: Something Moved team.
- `courier.spritefont`: DirectXTK sprite-font definition included with the project.
- Rain, blackout, correct, and incorrect WAV files: existing project runtime audio. Their source evidence must remain with the team records; do not add the uncleared loose `ambient_horror` or `freezer` files from the source library.

## Source-library policy

The raw `SomethingMoved_AssetLibrary` and Blender starter folders are working materials, not runtime dependencies. Do not commit or redistribute entire source packs. Preserve original license/readme files in local team records and include only assets actually used by the game.
